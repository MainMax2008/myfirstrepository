# Баталия на 14-й линии

## О проекте

- **Вариант:**  Морской бой 
- **Язык:** Python
- **Автор:** Шаховалов Максим Алексеевич, Б11

Консольная реализация классической игры «Морской бой» для двух игроков с поддержкой цветного интерфейса и перерисовкой экрана без скроллинга.
## Требования

- **Python 3.10** или выше
- **Система сборки и зависимости:** не требуются (проект реализован исключительно на стандартной библиотеке Python: `sys`, `os`, `random`, `unittest`)

## Сборка

Установка зависимостей (из директории `project/`):

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```
