# Баталия на 14-й линии

## О проекте

- **Вариант:**  Морской бой 
- **Язык:** Python
- **Автор:** Шаховалов Максим Алексеевич, Б11

Консольная реализация классической игры «Морской бой» для двух игроков с поддержкой цветного интерфейса и перерисовкой экрана без скроллинга.
## Требования

- **Python 3.10** или выше
- **Система сборки и зависимости:** не требуются (проект реализован исключительно на стандартной библиотеке Python: `sys`, `os`, `dataclasses`, `unittest`, `subprocess`)

## Сборка

Установка зависимостей (из директории `project/`) (необязательно, т.к. используется стандартная библиотека Python):

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Как играть

1. **Режим Hotseat:** игроки делают ходы по очереди за одним экраном. После расстановки экран полностью очищается, сохраняя «туман войны».
2. **Расстановка флота:** каждый игрок расставляет 10 кораблей (1-палубный 4 шт., 2-палубный 3 шт., 3-палубный 2 шт., 4-палубный 1 шт.):
   - ввод координат носа/начала судна (например, `A1`, `b5`, `J10`);
   - выбор ориентации: `h` — по горизонтали, `v` — по вертикали (для многопалубных).
3. **Боевой режим:**
   - выстрел осуществляется вводом координаты (буква столбца `A`–`J` и номер строки `1`–`10`);
   - при полном потоплении корабля клетки ореола автоматически помечаются промахами.
4. **Обозначения на поле:**
   - `~` — неразведанная вода;
   - `•` — промах;
   - `X` — попадание в палубу / уничтоженный корабль;
   - `■` — палуба своего корабля (видна только на этапе расстановки своего флота).
5. **Цель игры:** первым полностью уничтожить все корабли флотилии соперника.
6. **Остановка игры:** если необходимо прервать бой досрочно, используйте сочетание `Ctrl + C` или `Ctrl + D`.

## Известные ограничения

- **Поддержка ANSI escape-кодов:** для корректного цветного вывода, очистки экрана без скролла и возврата курсора в начало требуется современный терминал (Windows Terminal, PowerShell, терминалы Linux/macOS). В устаревшем классическом `cmd.exe` (без включённого режима Virtual Terminal Sequences) управляющие коды и цвета могут отображаться как сырой текст.
- **Минимальный размер окна:** во время фазы боя два поля отрисовываются рядом (Side-by-Side). Для предотвращения нежелательного переноса строк ширина окна консоли должна быть не менее 55–60 символов, а высота — не менее 18–20 строк.
- **Игровой режим:** реализован исключительно локальный мультиплеер для двух человек за одним компьютером (Hotseat). Игра против компьютера (бота) и сетевой режим по сети не поддерживаются.
