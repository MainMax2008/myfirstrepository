# Варианты итогового проекта

Нужно выбрать **ровно один** из трёх проектов и реализовать его.

| № | Проект                | Ключевая особенность                    |
|---|-----------------------|------------------------------------------|
| 1 | Шашки                 | Правила русских шашек, два игрока        |
| 2 | Морской бой           | Два этапа расстановки, цвета в консоли   |
| 3 | Змейка                | **Обязательная** многопоточность         |

> ⚠️ Если выбираете проект 3 («Змейка») — реализация **обязана**
> использовать минимум два потока и синхронизацию между ними. Без этого
> проект не будет оценён высоко.
