# Как работать с репозиторием

## Общий процесс

1. Определитесь с проектом (см. `tasks/`).
2. Скопируйте `project/README.template.md` в `project/README.md` и заполните
   его под свой проект (после этого `project/README.template.md` следует удалить).
3. Реализуйте проект **по этапам**. Каждый этап — отдельный осмысленный
   коммит.
4. Перед сдачей убедитесь, что проект собирается «с нуля» по инструкции из
   вашего `project/README.md`.

## Коммиты

- Делайте **3–5 коммитов** на проект.
- Каждый коммит — законченный этап. Пример разбиения:
  1. `Инициализация проекта и структура каталогов`
  2. `Реализация игровой логики и правил`
  3. `Пользовательский интерфейс и ввод команд`
  4. `Обработка ошибок и тесты`
  5. `README, сборка и финальные правки`
- Сообщение коммита должно быть понятным без чтения diff:
  - Плохо: `fix`, `update`, `wip`, `123`.
  - Хорошо: `Добавлен разбор хода игрока и проверка правил взятия`.

Полные правила — в [`docs/git-guidelines.md`](./docs/git-guidelines.md).
